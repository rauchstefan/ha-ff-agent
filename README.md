# FF Agent für Home Assistant

Custom-Integration für [Home Assistant](https://www.home-assistant.io/), installierbar
über [HACS](https://hacs.xyz/), die **FF Agent** in Home Assistant verfügbar macht.

> **Status:** in Planung – noch keine installierbare Version.

## Ziel

Alarmierungen und Einsatzinformationen aus FF Agent in Home Assistant nutzen, z. B. um
bei einem Alarm Licht einzuschalten, Benachrichtigungen auszulösen oder Einsatzdaten
auf einem Dashboard anzuzeigen. Details: [docs/projekt-brief.md](docs/projekt-brief.md).

## Installation (sobald verfügbar)

1. In HACS „Benutzerdefinierte Repositories“ öffnen und dieses Repository als Typ
   „Integration“ hinzufügen.
2. „FF Agent“ installieren und Home Assistant neu starten.
3. Unter *Einstellungen → Geräte & Dienste → Integration hinzufügen* „FF Agent“ wählen.
